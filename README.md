## Deskripsi Proyek

Proyek ini merupakan aplikasi mobile yang dibangun menggunakan **React Expo** untuk menyediakan berbagai informasi terkait profil, proyek, dan kontak. Aplikasi ini memungkinkan pengguna untuk melihat data pribadi dan menghubungi melalui berbagai platform seperti email, GitHub, dan WhatsApp.

Aplikasi ini memiliki beberapa halaman utama, yaitu:

- **Halaman Kontak**: Menampilkan informasi kontak seperti email, GitHub, dan WhatsApp.
- **Halaman Proyek**: Menampilkan informasi mengenai proyek-proyek yang telah dikerjakan.
- **Halaman Profil**: Menampilkan profil diri dan keterampilan teknis yang dimiliki.

## Instruksi Cara Menjalankan Proyek

Ikuti langkah-langkah di bawah ini untuk menjalankan proyek ini secara lokal:

### 1. Persiapan

Pastikan Anda sudah menginstal beberapa hal berikut:

- [Node.js](https://nodejs.org/) (disarankan versi LTS)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)

### 2. Instalasi Dependensi

Setelah menginstal Expo CLI, ikuti langkah-langkah berikut:

- Clone repositori proyek ini ke komputer Anda.

  ```bash
  git clone https://github.com/zihunn/uts-mobile-2.git
  ```

- Masuk ke dalam direktori proyek.

  ```bash
  cd [nama-direktori-proyek]
  ```

- Instal dependensi yang diperlukan..

  ```bash
  npm install
  ```

### 3. Menjalankan Aplikasi

Untuk memulai aplikasi di perangkat Anda, jalankan perintah berikut:

  ```bash
  expo start
  ```
